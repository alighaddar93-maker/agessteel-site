AGES STEEL — Connexion Dropbox

Brancher le site sur le Dropbox de l'ingénieur (à faire une seule fois, avec lui).

Vérification...

ÉTAPE 1 — L'ingénieur crée l'application Dropbox (5 minutes)

  1. Sur son ordinateur, connecté à son compte Dropbox, il ouvre : dropbox.com/developers/apps
  2. Bouton « Create app »
  3. Il choisit : Scoped access → App folder → nom : AgesStyle-Catalogue
    (« App folder » = le site ne verra QUE ce dossier, jamais le reste de son Dropbox)
  4. Onglet Permissions : cocher files.metadata.read et files.content.read, puis Submit
  5. Onglet Settings : dans « Redirect URIs », coller http://localhost:4600/dropbox-retour puis Add
  6. Toujours dans Settings : copier la App key et le App secret (cliquer « Show » pour le secret) → les coller ci-dessous

ÉTAPE 2 — Coller les clés et connecter


Dropbox va demander à l'ingénieur d'autoriser l'accès (il doit être connecté à son compte dans ce navigateur). Ensuite, tout est automatique.

ÉTAPE 2 BIS — Si l'ingénieur autorise depuis SON ordinateur (à distance)

  1. Tu lui envoies le lien d'autorisation (bouton ci-dessous pour le copier)
  2. Il l'ouvre, se connecte à son Dropbox, clique Autoriser
  3. Il verra une page d'erreur « localhost refused to connect » — c'est normal ! Le code est dans la barre d'adresse.
  4. Il copie l'adresse complète de la barre du navigateur et te l'envoie immédiatement (WhatsApp) — ⚠️ le code expire en quelques minutes
  5. Tu la colles ici et tu valides tout de suite :

ÉTAPE 3 — L'ingénieur remplit son dossier

  1. Un dossier Applications/AgesStyle-Catalogue apparaît dans son Dropbox
  2. Dedans, il crée ses catégories : Portails, Escaliers, Tables...
  3. Dans chaque catégorie, il met ses photos (bien nommées : portail-royal.jpg)
  4. Le site se met à jour tout seul (au maximum 60 secondes après)
